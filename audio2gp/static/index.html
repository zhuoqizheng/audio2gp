audio2gp

把一首完整混音拆成鼓、贝斯、人声和其他声部，自动记谱、分析和弦，并导出可继续编辑的多轨 .gp5；也可以只导出 MIDI。

仅监听 127.0.0.1 音频不上传云端 无 LLM 记谱

STEP 1

上传与参数

支持 MP3、WAV、FLAC、M4A、OGG 等。默认上限 200 MB / 10 分钟，可在启动参数中调整。

为什么需要完整混音？ Demucs 会先从混音中分离四类声部，再分别转谱。若你已经有干净的单独轨，也可以把该轨当作混音上传，并在“参与转谱的声部”中只勾选对应声部。

隐私：所有模型推理、量化、GP5 生成均在本机完成；浏览器只访问 localhost。

参与转谱的声部

例如原曲只有吉他和人声，可只勾选 “other” 与 “vocals”，得到两轨谱。GP5 模式至少需要一个能产生轨道的声部；仅 MIDI 模式只需至少选择一个声部。和弦分析只使用勾选的 other / bass / vocals 和声声部。

        处理警告 
        
    
      
    
    
    

    
    
      
    这个工具做了什么，没做什么
    
      
    
        
    
          
    流程
    
          
    Demucs 分离 → 节拍/强拍与鼓速校正 → Basic Pitch 旋律转录 + 鼓点频段分类 → 量化与鬼音清理 → 和弦分析 → 手型 Viterbi 指法（GP5 模式）→ 多轨 GP5 或仅 MIDI。所有步骤都在本机完成。
    
        
    
        
    
          
    边界
    
          
    不接入 LLM，不做云端推理，不抓取商业谱库。在线编辑器只支持改弦/品、删除音符和静音；不是完整的 Guitar Pro 替代品。
    
        
    
        
    
          
    结果状态
    
          
    GP5 生成失败时仍会交付 MIDI、和弦与 ZIP，任务标记为“部分成功”。仅 MIDI 模式属于正常完成，不生成 GP5 或在线编辑状态；MIDI 可导入其他制谱软件继续修正。
